# 🚨 KIRA – AI Powered Women Safety System

**KIRA App** is an advanced, **AI-driven mobile safety application** designed to provide instant assistance to women during emergency situations.

By leveraging **smartphone sensors, AI voice recognition, real-time tracking, and emergency automation**, KIRA ensures that **help is just a shake or a word away**.

---

## 🌟 Overview

In dangerous situations, unlocking a phone and manually opening an app may not always be possible.

**KIRA solves this problem** through an intelligent, multi-trigger emergency system that can automatically detect distress and instantly notify trusted contacts.

The app combines:

- 📍 Real-Time Location Tracking  
- 🎙️ AI Voice SOS Detection  
- 📳 Smart Shake Detection  
- 📹 Automatic Evidence Recording  
- 📶 Offline Emergency Alerts  
- 🧠 AI-Based Safety Monitoring  

---

# 🚀 Key Features

## 🆘 Multi-Trigger SOS System

Never worry about manually unlocking your phone during emergencies.

KIRA supports multiple emergency triggers:

### 🔴 SOS Button
A prominent emergency button on the dashboard for instant SOS activation.

### 🎙️ AI Voice SOS
Recognizes distress keywords such as:

- **"Help"**
- **"Bachao"**
- **"Save Me"**

Automatically activates emergency mode while the app is active.

### 📳 Smart Shake Detection
Emergency trigger activates only after:

**3 strong shakes within 2 seconds**

This minimizes false alarms caused by accidental movement.

### 🔘 Power Button Trigger
Rapidly press the **power button 3 times** to instantly trigger SOS.

---

## 🛡️ Smart Monitoring & Evidence

### ⏳ Safe Walk Timer
Walking alone?

Set a safety timer.

If the user fails to check in before the timer ends, **KIRA automatically triggers SOS**.

### 🎥 Automatic Evidence Recording
Upon SOS activation:

- Background audio recording starts
- Camera recording begins automatically
- Evidence is securely stored for emergency use

### ⚠️ Risk Status Monitoring
Real-time environmental monitoring provides:

- **Low Risk**
- **Medium Risk**
- **High Risk**

based on surrounding safety conditions.

---

## 📞 Emergency Communication

### 📶 Offline SOS
No internet?

No problem.

KIRA sends emergency SMS alerts with:

- 📍 Live Location
- 🔗 Maps Tracking Link
- 🚨 Emergency Message

### ☎️ Priority Calling System
Automatically contacts trusted people in order of priority:

```text
Father → Friend → Guardian → Police (112)
```

If one contact does not respond, the next person is called automatically.

### 📍 Live Tracking
Shares a **Google Maps-compatible live location link** via SMS for real-time tracking.

---

# 📋 Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/kira-women-safety-app.git
```

---

## 2️⃣ Firebase Setup

1. Open **Firebase Console**
2. Create a Firebase Project
3. Add your **google-services.json** file into:

```text
app/
```

Enable:

- **Email/Password Authentication**
- **Realtime Database**

---

## 3️⃣ Sync Gradle

Sync the project to install:

- Firebase Libraries
- osmdroid
- Google Services

---

## 4️⃣ Build APK

Go to:

```text
Build > Build APK(s)
```

Generate the installable APK file.
